# Changelog — SmartThings Edge 드라이버

허브 안에서 도는 Edge 드라이버(`edge/`)의 변경 이력입니다. 드라이버는 서버 컨테이너와 버전이 따로 돌고(`src/driver_version.lua`, 태그 `edge-vX.Y.Z`), 사용자는 GitHub 릴리스가 아니라 SmartThings 채널을 통해 자동으로 업데이트를 받습니다. 서버의 이력은 [../CHANGELOG.md](../CHANGELOG.md)에 있습니다.

## [Unreleased]

## [0.1.1] - 2026-10-31

서버 v0.1.1 과 함께 쓰는 것을 권장합니다(휴식 모드 재시도, 세션 전에 거절된 요청의 `last_standby` 기록).

### 추가

- **마지막 휴식 모드 줄** — `마지막 깨우기` 아래에 `마지막 휴식 모드`(시각 · 결과 · 실패 사유: "Remote Play 사용 중", "PS5 가 연결을 끊음", "로그인 비밀번호 걸림", "아직 켜짐" 등) 줄이 생기고, 루틴 조건으로 `마지막 휴식 모드 결과` 를 고를 수 있습니다. 스위치를 꺼서 실패하면 토글이 되돌아오면서 이 줄에 이유가 바로 보입니다. 기존 장치는 `ps5.v3` 화면으로 자동으로 옮겨집니다

### 변경

- 휴식 모드 요청의 대기 시간을 100초로 늘렸습니다(서버가 거절당한 세션을 20초 뒤 한 번 더 시도하는 시간까지 기다립니다)
- **깨우는 동안 스위치가 깜빡이지 않습니다** — 블루투스 신호에 PS5 가 응답한 뒤 부팅하는 10~20초 동안 서버는 아직 꺼짐이라 답하는데, 그 사이 확인이 들어오면 스위치가 켜짐 → 꺼짐 → 켜짐으로 흔들렸습니다. 깨우기 창이 열려 있는 동안은 켜짐을 유지합니다
- 깨우기 요청의 대기 시간을 120초로 늘렸습니다. 서버의 자동 경로(네트워크 30초 + 블루투스 3회)가 60초를 넘길 수 있어 성공 직전에 되돌아가는 일이 있었습니다
- **검색으로 만든 장치가 바로 응답합니다** — 허브는 `init` 뒤에 `added` 를 보내므로 첫 확인이 주소 없이 돌아 다음 주기까지 오프라인으로 보였습니다. 주소를 받는 즉시 한 번 더 확인합니다
- 같은 깨우기 창에 스위치를 두 번 켜도 추적 루프는 하나만 돕니다. 프로필 이전은 허브가 보고하는 프로필 이름을 먼저 보고 판단합니다(이전 요청은 비동기라 기록만으로는 끝난 것이 아닙니다)
- 깨우기 로그가 서버 응답의 실제 자리(`bluetooth.status_text` · `attempts`)를 읽고 경로(`method`)도 남깁니다

## [0.1.0] - 2026-10-28

### 추가

- **장치 화면** — 스위치 아래에 `전원 상태`(켜짐 · 휴식 모드 · 꺼짐 · 깨우는 중 · 알 수 없음, 타일에도 표시되고 루틴 조건으로 쓸 수 있음), `상태`(서버 연결과 마지막 확인 시각), `마지막 깨우기`(시각 · 경로 · 결과), `블루투스 동글`(칩셋과 준비 여부), `Remote Play`(등록 여부와 닉네임), `버전` 줄이 생겼습니다. 루틴 조건으로 `서버 연결`, `마지막 깨우기 결과`, `블루투스`, `Remote Play 등록`도 고를 수 있습니다. 카테고리가 `Switch` 라 앱에서 아이콘을 바꿀 수 있습니다. 기존 장치는 `ps5.v2` 화면으로 자동으로 옮겨집니다(다시 추가할 필요 없음)
- **첫 드라이버** — 주변 기기 검색이 SSDP 로 ps5-control 서버를 찾아 주소가 채워진 `PS5` 장치를 만들고(서버의 Remote Play 닉네임이 있으면 그 이름), 서버 주소가 바뀌면 다음 실패 때 다시 찾아 따라갑니다(5분에 한 번). 장치 설정의 `서버 주소` 를 채우면 언제나 그 값이 우선합니다. 응답이 없고 장치도 없으면 주소를 손으로 넣을 장치를 하나 만듭니다. 그 뒤 ps5-control 의 `GET /status` 를 주기(10초~5분, 기본 30초)마다 물어 스위치에 보여 줍니다(켜짐 = 켜짐, 휴식 모드·꺼짐 = 꺼짐). 스위치를 켜면 `POST /wake` 로 깨우기(휴식 모드면 네트워크, 아니면 블루투스)를 보내고 90초 동안 5초마다 확인하며, 안 켜지면 스위치가 되돌아갑니다. 스위치를 끄면 `POST /standby` 로 휴식 모드로 보내고, 서버에 Remote Play 등록이 없으면 토글이 되돌아갑니다(환경설정 `스위치 끄기 동작` 을 `무시` 로 바꿀 수 있음). 환경설정 `API 시크릿` 은 서버의 API 시크릿과 같게 넣습니다. 서버에 닿지 않으면 장치가 오프라인으로 표시됩니다
