# Changelog — SmartThings Edge 드라이버

허브 안에서 도는 Edge 드라이버(`edge/`)의 변경 이력입니다. 드라이버는 서버 컨테이너와 버전이 따로 돌고(`src/driver_version.lua`, 태그 `edge-vX.Y.Z`), 사용자는 GitHub 릴리스가 아니라 SmartThings 채널을 통해 자동으로 업데이트를 받습니다. 서버의 이력은 [../CHANGELOG.md](../CHANGELOG.md)에 있습니다.

## [Unreleased]

### 추가

- **첫 드라이버** — 주변 기기 검색으로 `PS5` 장치를 만들고, 장치 설정의 서버 주소·포트로 ps5-control 의 `GET /status` 를 주기(10초~5분, 기본 30초)마다 물어 스위치에 보여 줍니다(켜짐 = 켜짐, 휴식 모드·꺼짐 = 꺼짐). 스위치를 켜면 `POST /wake` 로 깨우기(휴식 모드면 네트워크, 아니면 블루투스)를 보내고 90초 동안 5초마다 확인하며, 안 켜지면 스위치가 되돌아갑니다. 스위치를 끄면 `POST /standby` 로 휴식 모드로 보내고, 서버에 Remote Play 등록이 없으면 토글이 되돌아갑니다(환경설정 `스위치 끄기 동작` 을 `무시` 로 바꿀 수 있음). 환경설정 `API 시크릿` 은 서버의 API 시크릿과 같게 넣습니다. 서버에 닿지 않으면 장치가 오프라인으로 표시됩니다
