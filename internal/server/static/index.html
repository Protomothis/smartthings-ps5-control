Remote Play 등록 (휴식 모드 · 네트워크 깨우기)

    
PS5 에 Remote Play 클라이언트로 등록하면 휴식 모드로 보낼 수 있고, 휴식 모드에서는 블루투스 없이 네트워크로 깨웁니다. PS5 설정 → 시스템 → 리모트 플레이에서 "리모트 플레이 활성화" 가 켜져 있어야 합니다.

    
확인 전

    

    

      
      
[PSN 로그인] 을 눌러 새 탭에서 로그인하면 "redirect" 페이지로 갑니다. 그 페이지의 주소를 복사해 아래에 붙여넣고 [계정 ID 가져오기] 를 누르세요. 숫자 계정 ID 를 이미 안다면 그 값을 넣어도 됩니다.

      

        
      

      
      

        
      

      
      
      
      
      

        
        
      

    

    

  


  

    
듀얼센스에서 주소 읽기

    
듀얼센스를 이 PC 에 USB 로 꽂고 버튼을 누르면 크롬 WebHID 로 컨트롤러 주소와 마지막으로 페어링된 PS5 주소를 읽어 위 칸에 채웁니다. 서버에는 아무것도 꽂을 필요가 없습니다.
